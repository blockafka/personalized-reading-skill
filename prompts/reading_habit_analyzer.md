# 阅读偏好分析 Prompt

## 任务

你将收到 **{name}** 的原材料（飞书消息、文档内容等）。
从中提取他的阅读偏好与内容消费习惯，用于构建 Reading Habit 画像。

**原则：只提取与内容消费相关的信号，忽略纯工作协作内容。不要推断，有依据才写，没有就标注"原材料不足"。**

---

## 提取维度

### 1. 高频主题与子主题

统计原材料中出现 3 次以上的主题词、技术名词、项目名：

- 直接出现的技术词（如 vLLM、FlashAttention、Rust async）
- 他主动分享或转发的内容中的核心词
- 他在讨论中反复提及的概念

按主题归类：

| 主题 | 子主题 / 关键词 | 出现次数 |
|------|--------------|---------|
| AI / 机器学习 | LLM、RAG、agents… | N |
| 编程 / 工程 | Rust、Python… | N |
| 创业 / 商业 | … | N |
| 其他 | … | N |

```
输出格式：
高频词（≥3次）：[词 → 出现次数，按主题分组]
高频词（1-2次，供参考）：[词列表]
```

---

### 2. 偏好的信息类型

从他分享、转发、评论的内容中识别他实际消费的信息类型：

| 信息类型 | 识别信号 |
|---------|---------|
| 新闻快讯 | 转发突发事件、简短评论"刚出来的" |
| 深度分析 / 观点 | 分享长文并附评论，讨论"为什么" |
| 教程 / How-to | 分享操作指南、代码示例 |
| 案例研究 | 分享"某公司怎么做的"类内容 |
| 工具发布 / 项目介绍 | 分享 GitHub 链接、新工具 |
| 讨论 / 争论 | 转发 HN/Reddit 讨论帖 |
| 吐槽 / 反思 | 分享踩坑记录、反思文章 |

```
输出格式：
主要信息类型：[类型列表，按频率排序]
偶尔出现：[类型列表]
从未出现：[类型列表]
```

---

### 3. 内容风格与密度偏好

从他分享的内容风格和他自己的评论方式判断：

**内容风格**：
- **理性严谨**：分享有数据、有论证的文章；评论时引用数据
- **犀利直接**：喜欢"直接说结论"类文章；评论简短有力
- **技术化**：分享含代码/架构图的内容；评论涉及实现细节
- **叙事化**：分享有故事背景的文章；评论关注背景和动机
- **幽默**：分享有梗的内容；评论带幽默感

**信息密度**：
- **高密度**：分享的文章普遍较长，评论显示他认真读了
- **轻松浏览**：分享短内容居多，评论停留在表面

```
输出格式：
内容风格：[风格列表，按频率排序]
信息密度：[高密度/轻松浏览/混合]
依据：[1-2 条原文引用]
```

---

### 4. 数据源偏好

从他分享的链接域名、引用来源识别：

| 来源 | source 枚举值 | 识别信号 |
|------|-------------|---------|
| Hacker News | 0 | news.ycombinator.com 链接，"HN 上看到" |
| Twitter / X | 1 | twitter.com / x.com 链接，"推上" |
| arxiv | 2 | arxiv.org 链接，论文标题 |
| GitHub Trending | 3 | github.com 链接，"GitHub 上" |
| Reddit | 4 | reddit.com 链接，"Reddit 上" |

```
输出格式：
主要来源：[来源列表，按频率排序]
偶尔来源：[来源列表]
未见来源：[来源列表]
```

---

### 5. 新鲜度偏好

从他分享内容的发布时间分布判断：

- **突发优先**：经常分享当天发布的内容，评论带"刚出来""刚看到"
- **近期为主**：分享内容集中在最近一周内
- **常青内容也行**：经常分享几个月甚至几年前的经典文章

```
输出格式：
新鲜度偏好：[突发优先/近期为主/常青内容也行]
依据：[1-2 条原文引用]
```

---

### 6. 热度与领域深度偏好

**热度偏好**：
- **大众热点**：经常提"HN 首页""Twitter 热搜"，关注大家都在聊的
- **小众深水区**：分享冷门但高质量的内容，从不提热度
- **都行**：两类都有

**领域深度**：
- **入门**：分享的内容以科普、入门教程为主
- **中级**：有一定技术深度，假设读者有基础
- **专业**：分享论文、源码分析、架构深度解析

```
输出格式：
热度偏好：[大众热点/小众深水区/都行]
领域深度：[入门/中级/专业]
依据：[1-2 条原文引用]
```

---

### 7. 屏蔽信号

从他明确表达不感兴趣、负面评价、主动跳过的内容中提取：

- 直接表达："不看 NFT 的东西"、"这种营销文章没意思"
- 隐性信号：某类话题从不参与讨论，从不转发

```
输出格式：
明确屏蔽（有原文）：[话题/关键词 → 原文引用]
推断屏蔽（无原文，仅推断）：[话题/关键词 → 推断依据]
```

---

## 输出要求

- 语言：中文
- 没有信息的维度：标注 `（原材料不足，建议追加相关消息记录）`
- 有原文依据的结论：加引号标注原话
- 输出结果直接用于生成 reading_habit.md，要求具体可执行，不要写"可能""倾向于"这类模糊表述

  }
