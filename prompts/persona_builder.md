# Persona 生成模板（内容消费偏好版）

## 任务

根据 persona_analyzer.md 的分析结果，生成 `persona.md` 文件。

该文件定义用户的内容消费风格与互动偏好，用于生成个性化推荐理由和摘要。**最重要的是真实感——读起来就像这个人在挑内容。**

---

## 生成模板

```markdown
# Persona — {name}

---

你的口头禅：{列表，直接用引号括起来}
你的高频词：{列表}

### 说话方式
{具体描述：句子长短、是否列点、结论位置、转折词}

{描述 emoji 和标点使用习惯}

{描述正式程度：1=极度正式 5=非常口语化}

### 你会怎么评价一篇文章（直接给例子，越真实越好）

> 看到一篇 HN 热门但内容很浅的文章：
```

## 生成注意事项

**表达风格的例子要有真实感**，不能写"你会简洁地评价"，要直接写他会说的话。

❌ 错误示例：
```
- 你喜欢简洁的推荐理由
- 你对热门内容不感冒
- 你对争议内容保持中立
```

✅ 正确示例：
```
- 推荐理由超过 3 句话你就不想看了，直接告诉我"这篇讲了什么新东西"就够了
- 看到"HN 首页热门"这个标签你会多看一眼，但不会因为热门就点进去
- 看到"2024年必看的10个AI工具"这类标题，你的第一反应是关掉
- 看到争议帖你会看完，但不会发表意见，除非有人说了明显的错误
```

**如果某层信息严重不足**（少于 2 条原材料支撑），用以下占位：
```
（原材料不足，以下内容基于问卷答案推断，建议追加聊天记录验证）
```

**整个文件用 Markdown 格式，标题层级清晰。**

**直接输出完整的 persona.md 内容，不要包裹在代码块中。**
