# Reading Habit 生成模板

## 任务

根据 reading_habit_analyzer.md 的分析结果 + intake.md 的问卷数据，生成 `reading_habit.md` 文件内容。

该文件将作为用户画像的核心部分，让推荐系统能"代替"这个人筛选内容。

---

## 生成注意事项

1. **权重判断规则**：
   - 问卷选择 + 原材料高频（≥5次）→ 高权重
   - 问卷选择 + 原材料中频（2-4次）→ 中权重
   - 仅问卷选择，原材料未见 → 低权重，标注"近期衰减"
   - 仅原材料高频，问卷未选 → 中权重，标注"新发现"

2. **信息类型优先级**：
   - 问卷选择的类型 → 优先
   - 原材料中频繁出现但问卷未选 → 一般
   - 原材料中从未出现的类型 → 不写入

3. **内容偏好参数**：
   - 优先使用问卷答案
   - 如果问卷答案与原材料分析冲突，两者都写，标注"问卷填写 X，但原材料显示 Y，建议确认"

4. **关键词去重与归类**：
   - 同义词合并（如 "LLM" 和 "大语言模型"）
   - 按技术栈/项目/概念分类，便于后续查询扩展

5. **屏蔽关键词**：
   - 有原文引用的优先级高于推断
   - 如果原材料不足，只写问卷填写的屏蔽词

6. **整个文件用 Markdown 格式，标题层级清晰**

7. **如果某个维度信息严重不足**（问卷跳过 + 原材料无信息），用以下占位：
   ```
   （信息不足，建议追加飞书消息记录或手动补充）
   ```

---

## 输出要求

- 语言：中文
- 直接输出完整的 reading_habit.md 内容，不要包裹在代码块中
- 确保所有权重判断有明确依据（问卷 or 原材料）
- 更新记录中注明数据来源（问卷/飞书消息/文档）
