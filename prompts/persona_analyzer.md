# 内容消费偏好分析 Prompt

## 任务

你将收到 **{name}** 的原材料（飞书消息、文档内容等）。
从中提取他在内容消费场景下的表达风格与互动偏好，用于构建 Persona 画像。

**场景适配：从"工作沟通"改为"内容消费偏好"。**

**原则：只提取与内容消费相关的风格特征，忽略纯工作协作内容。不要推断，有依据才写，没有就标注"原材料不足"。**

---

## 提取维度

### 1. 表达风格（内容消费场景）

分析他在分享、评论、讨论技术内容时的语言特征：

**用词统计**
- 高频词（出现 3 次以上的词/短语）
- 口头禅（固定搭配，如"这篇不错""值得一看""有点意思"）
- 技术术语密度（高/中/低）

**句式特征**
- 平均句长（短句 <15 字 / 中等 15-40 字 / 长句 >40 字）
- 是否爱用列表/分点
- 评论位置（先给结论 vs 先描述内容）
- 转折词使用频率（"但是""不过""话说回来"）

**情绪信号**
- emoji 使用习惯（无/偶尔/频繁，常用哪类）
- 标点密度（感叹号/省略号的使用）
- 正式程度（1=极度正式 5=非常口语化）
- 情绪倾向（正向/负向/中性，他评论内容时的情绪基调）

```
输出格式：
口头禅：["xxx", ...]
高频词：["xxx", ...]
技术术语密度：[高/中/低]
句式：[描述]
emoji：[无/偶尔/频繁，类型]
正式程度：[1-5]
情绪倾向：[正向/负向/中性]
```

---

### 2. 阅读动机偏好

从他的提问方式、评论重点判断：

- **偏好"为什么"**：关注原理、动机、设计决策（"为什么这么设计"）
- **偏好"是什么"**：关注定义、功能、用法（"这是什么"）
- **偏好"怎么做"**：关注实现、步骤、代码（"怎么实现的"）
- **偏好对比分析**：喜欢"A vs B"类讨论
- **偏好争议内容**：主动参与争论，喜欢高争议话题

```
输出格式：
主要动机：[为什么/是什么/怎么做/对比分析/争议内容]
依据：[1-2 条原文引用]
```

---

### 3. 推荐理由偏好

从他分享内容时的附加评论判断：

- **简洁型**：只给核心论点，1-2 句话（"这篇讲了 X 的优化思路"）
- **详细型**：给完整摘要，3-5 句话，覆盖背景+方法+结论
- **核心论点型**：只说"为什么值得看"（"这个 benchmark 很有说服力"）
- **内容摘要型**：复述文章结构（"第一部分讲 X，第二部分讲 Y"）

```
输出格式：
推荐理由风格：[简洁/详细/核心论点/内容摘要]
典型示例：[1-2 条原文引用]
```

---

### 4. 对"热门"和"争议"内容的态度

**对热门内容**：
- **在意热度**：会主动提"HN 首页""GitHub Trending 第一"
- **只在意质量**：从不提热度，只评价内容本身
- **反感热门**：对热门内容有负面评价（"又是炒作""标题党"）

**对争议内容**：
- **主动参与**：看到争论帖会发表意见
- **观望**：看但不评论
- **回避**：不转发争议内容

```
输出格式：
对热门的态度：[在意/不在意/反感]
对争议的态度：[主动参与/观望/回避]
依据：[1-2 条原文引用]
```

---

### 5. 互动偏好

从他回复、评论、提问的方式判断：

- **回复长度**：习惯长回复（>50字）还是短回复（<20字）
- **提问方式**：直接问 vs 先铺垫背景
- **反对方式**：直接否定 vs 委婉质疑 vs 提问引导
- **对"推荐给你"的反应**：欢迎 vs 无感 vs 反感

```
输出格式：
回复长度：[长/中/短]
提问方式：[描述]
反对方式：[描述 + 示例话术]
对推荐的态度：[欢迎/无感/反感]
```

---
